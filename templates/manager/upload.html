CSV File Structure Guide

Your CSV file must have the exact column headers listed below. The order of columns does not matter, but the names must match exactly.

Column Header Description Example
sku Required Unique identifier for your product. Image files must be named using this SKU (e.g., TSHIRT01.jpg). TSHIRT01
